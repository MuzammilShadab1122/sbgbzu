# 🚀 AWS Student Builders BZU — Portfolio & Leaderboard

An interactive, premium-designed web portal showcasing the directory, events, blog, and builder leaderboard profiles for the BZU chapter of AWS Student Builders.

If you are a new person setting up this project for the first time, please follow our step-by-step setup guide:

👉 **[SETUP_GUIDE.md](file:///d:/My%20Projects/SBG/SETUP_GUIDE.md)**

3. Activating **Apache** and **MySQL** services
4. Running the project (via local PHP server or XAMPP)

---

## ⚡ Quick Run (If XAMPP is already installed)

1. Open **XAMPP Control Panel** and start **MySQL** (and optionally **Apache**).
2. Open your command terminal in this directory and start the PHP development server:
   ```cmd
   php -S localhost:8000
   ```
3. Open **[http://localhost:8000](http://localhost:8000)** in your browser.
4. The database `sbg_portfolio` and its tables will be created and seeded automatically on the first load!
