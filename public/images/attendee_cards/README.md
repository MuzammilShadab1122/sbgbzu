# Attendee card artwork

Place the approved blank attendee-card background image at:

`public/images/attendee_cards/card_template.jpg`

Use the 1646 × 2048 JPEG template supplied for AWS Student Community Day 2026. Do not commit attendee personal photos or generated cards to this directory.

The application intentionally reads this artwork from the deployed filesystem path. The image asset will be installed on the EC2 server during the deployment step, after the code has been reviewed and merged.
